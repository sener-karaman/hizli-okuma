# Hızlı Okuyucu (çevrimdışı PWA)

EPUB / KEPUB / MOBI için hızlı okuma uygulaması. Kelime (RSVP), Akış ve Takip modları.
Hiçbir sunucuya veri göndermez; ilk açılıştan sonra tamamen internetsiz çalışır.

## GitHub Pages ile yayınlama
1. GitHub'da yeni bir repo aç (ör. `hizli-okuyucu`), bu klasördeki dosyaları yükle.
2. Settings → Pages → Branch: `main`, klasör: `/ (root)` → Save.
3. Birkaç dakika sonra `https://sener-karaman.github.io/hizli-okuma/` adresinde açılır.

## Telefona kurma
- **Android (Chrome):** sayfayı aç → ⋮ menü → *Uygulamayı yükle* / *Ana ekrana ekle*.
- **iPhone (Safari):** sayfayı aç → Paylaş → *Ana Ekrana Ekle*.

Bir kez internetle açtıktan sonra uçak modunda da çalışır.
